JobEngine

TypeScript roblox-ts Rojo MIT

A reusable "shift-based job" engine for RP / life-sim games. Handles the part that's the same in every one of these games — starting and ending a shift, passive income on a timer, AFK detection, time-based boost tiers, gamepass-gated jobs — so only the job-specific logic has to be written per game.

  • Passive income loop with AFK detection, warning, and auto-end
  • Time-based boost tiers applied to payout at shift end
  • Per-job Behavior plugin interface, loaded dynamically by job ID
  • Signal-based events for quests, XP, and analytics to subscribe to
  • Every integration point (payout, validation, tutorial gating) injected through one options object
const engine = new JobEngine({
	Jobs,
	Payout: (player, amount) => { ... },
	BehaviorsFolder: script.Parent.Behaviors,
});

engine.ShiftStarted.Connect((player, jobId) => {
	QuestSystem.AddValue(player, "Jobs started", 1);
});

UITransitions

TypeScript roblox-ts Rojo MIT

A lightweight menu/GUI transition engine for Roblox. Handles the part of a UI shell that's almost always hand-rolled — sliding screens in and out, hiding the HUD while a menu is open, hover-scale button feedback, and an "unseen content" notification dot that clears itself once the player actually looks at what it's pointing to.

  • Slide-in/slide-out transitions driven entirely by TweenService
  • Automatic opener-button ↔ ScreenGui wiring by name
  • HUD hide/restore while a designated menu is open
  • Notification-dot system that dismisses itself when its target scrolls into view
  • One extension point (RegisterExternalEvent) for all game-specific side effects
UITransitions.Initialize(hud, hudButtons, {
	Inventory: { HideHUD: false },
	Settings: { HideHUD: true },
});

UITransitions.RegisterExternalEvent("Settings", (opening) => {
	pauseGameplayInput(opening);
});
